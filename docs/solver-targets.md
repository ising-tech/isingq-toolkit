# 云端机型与具名本地求解器

普通用户流程使用[统一业务求解门面](guided-solve.md)，不向Agent暴露底层求解参数与准备依据。下文目标API保留为技术／兼容接口。

本分支实现YJ-REQ-0103／0104的显式求解目标入口，能力版本为`isingq-solver-target-v1`。这是开发候选，未发布或安装到用户运行时；现有版本号不代表新能力已公开可用。调用方须检查契约常量与实际公开方法，不能在缺能力时自动回退legacy云提交。

业务理解、模型配方、QUBO目标公式及业务解释沿用。新增的是确认环节选目标、按目标准备／提交／续查，以及每笔调用的来源和查阅位置。

新云目标为`{kind:'cloud',environment:'sit'|'prod',computer_type_id:目录实际ID}`；本地目标为`{kind:'local',profile_id:稳定连接ID}`。新入口没有默认目标。legacy start保持原云契约与2048本地边界，不充当新流程的隐式降级。

## 同一个求解确认环节

1. 从现有模型接续，展示目标选项与初步建议。目录匿名读取，本地来自当前用户／运行环境的配置。仅看本地可用`include_cloud:false`，无需等待云目录。零／一／多台配置均展示`local.management`提供的“添加／管理本地求解器”操作；它不是可执行目标，列出时不启动管理服务。用户选择后调用现有`isingq_solver_config_open`，由实际Host支持打开返回的URL或提供可点击入口。管理返回后重新读取本地列表，保留模型与已有合法选择；保存不提交，失效的选择说明原因并由用户重选。
2. 用户选择目标后继续给适配建议，但不改选、不自动改参数、不要求接受建议或等建议返回才能继续。未被推荐的可执行目标仍可选择。
3. prepare只作结构、实际能力、参数和文件检查；保存配置不提交，prepare也不上传／创建。ready=false时保留选择并说明硬性问题。云端上传按动态CSV字节阈值，严格超限才转真实NPZ，键为matrix。
4. Host展示本次业务范围、目标、数据去向及按目标适用的资源影响摘要（本地为设备占用，不主动列模式；云端展示适用参数并保留显式付款选择），取得用户明确确认后调用startTarget。preparation_token仅校验准备依据，不证明人类授权，也不增加一轮“接受建议”。
5. 实际目标、模型、参数、能力／报价或连接依据变化需重核适用确认；建议刷新不使确认失效。上传与创建始终按所选目标，不故障自动切换。

新云参数使用calculate_count、整数post_process=0／1与显式use_credit；免费项按契约false，付费不代选资金。旧gear不混入新接口。本地缺省task_mode由Core确定性规范化为2（精准），普通MCP/CLI传solver_options={}即可，不再询问或主动展示模式、三档区别或服务器后处理；“快点”等自然语言不改变内部模式。底层显式0／1／2仅保留兼容和诊断，合法高级参数与旧记录原样，不被新默认覆盖。实际模式继续留工具JSON、提交basis和记录供技术追溯。该默认不保证最优、性能或精度无损，不改变bit精度，也不代表修复设备问题。matrix_mode由已核实表示决定，不把云gear数字直接映射过去。

本地准备、确认、提交及结果／异常流程不展示云费用、算力券／余额选择，不索取云Key；切换到本地移除不适用云参数与待处理付款项。本地云平台计费明确为`billing.status=not_applicable, scope=cloud_platform, reason=local_target`，不等于模拟或所有本地成本为0；只有实际`execution_mode=simulation`才称模拟。云端付款、鉴权及账单未核实规则仍仅用于云目标。MCP初始化、建模引导和资源共用运行时`modelingGuide()`的目标规则，`task_mode`公开schema复用同一模式说明；不要再维护一份独立提示词。

## 本地配置与部署合同

基础录入只要求名称及完整http／https服务地址，可选独立设备网页地址。稳定ID及revision防止改名、排序和并发编辑串设备；配置文件私有、原子保存。取消不写入，保存不连接设备或创建任务。配置页使用loopback与有期限会话，独立sidecar使CLI返回后页面仍可录入；浏览器与Toolkit运行位置的网络条件分别说明。

标准准备／提交也不依赖用户手填高级合同。适配器内置版本化无表头、上三角QUBO／binary协议，基础名称＋地址即可使用。标准binary响应中的spin_config实际按0／1解码；显式兼容部署若声明spin结果域，必须提供映射。全1向量不猜域，native spin输入转换没有因此开放。

云端与本地采用相同服务边界：基础连接与已知QUBO协议可进入标准准备，实际maxScale、状态、客户端容量及明确部署覆盖均独立检查。maxPrecision=8bit仅为设备报告的计算精度，不能推出上传系数必须在±127内或只能为整数。未公布的上传系数范围、步长及服务端文件阈值标not_declared/provider_managed，如实未知，不据此判不兼容或阻断普通准备／提交，不要求普通用户提供完整硬件内部算法；也不承诺任意输入均支持或精度无损。显式整数／十进制步长等限制仍逐项校验。

Toolkit不自动量化、缩放、截断；Agent也不得凭bit精度或离线猜测修改既有模型、罚权、辅助位、编码或业务条件。离线量化模拟仅为明确标注假设的独立实验，不是设备能力证据或擅自改模理由。设备明确拒绝或结果异常时，保留原矩阵和记录，按原接口证据定位，不自动回退重编码或重提。ready只表示当前可核对合同已检查，不证明精度无损。

首次正常构造QUBO和罚权仍可按业务／数学依据进行。用户主动要求或确有已声明限制需要重建模时，说明实质变化、核验业务等价性，生成新模型与最终CSV，重新prepare并更新适用确认；旧提交依据不能用于实质变化后的模型。完整数值／量化算法及独立参考仅在实施客户端数值变换或承诺无损／精度适配时才成为前提，不作为普通提交前置；真正未实现的布局或客户端数学转换仍阻止。上述规则由运行时`numeric_model_policy`维护，并通过同源`target_guidance`进入MCP初始化、建模引导与资源；目标QUBO公开schema引用相同说明。

本地probe只调用设备config／runtime／status。即使合同缺失，成功取得的设备事实仍可查看；网络可达、能力已知、设备允许提交与结果有效分别表达。不会用power、Benchmark、onlyLoad或真实任务测试连通。认证仅可由显式本地credentialProvider提供，不读取云Key。

## 管理页的设备信息与公开机型

YJ-REQ-0105在原配置页增加两个卡片区域。打开／刷新已保存连接列表后，从Toolkit运行位置自动只读获取一轮设备config／runtime／status，最多2台并发，显示本次时间与真实设备信息；保留手动重新测试。保存本身不探测，云目录刷新也不额外检测设备，不持续轮询。部分接口失败仍保留已知字段；远端401／403是设备读取问题，不代表本机管理会话失效。检测绑定稳定ID、revision和当时地址，编辑或删除后不采用旧结果。同一连接保存与删除互斥，其他卡片继续操作。

正式管理页固定PROD并匿名读取目录，无环境选择；可信内部启动选项可提供固定SIT预览，明确标识且与正式会话隔离。页面浏览不替代MCP本次求解目标的明确选择。卡片分别展示标称规格与目录声明的实际范围，未知能力明确标注；公开目录不表示实时在线或用户具备权限。加载、空目录、限流及服务错误局部呈现，不提供固定名单或过期数据回退，也不持续轮询。设备图和原详情按钮打开同一只读弹窗，高级部署规则仍选填。

管理页的重复打开、跨进程防重、有期限会话及进程／监听端口回收，按[启动与资源生命周期规范](solver-manager-lifecycle.md)执行。页面可读写或close返回成功都不能单独证明资源已回收，须有实际退出与端口重新绑定证据。

## 每笔记录与恢复

v2记录持久保存原目标／环境／连接版本、当时API与网页依据、模型与文件摘要、有效参数、适配器版本／结果域／已生效规则及稳定唯一任务名，受理后补提供方任务号。同一个设备端ID可出现在多台设备，续查与查看不能仅按该ID或当前profile决定去向。删除／改名／改址不迁移历史，也不让未来新默认改变原结果域。

同键不同请求冲突；本地存储在异步请求前原子预留。相同求解矩阵存在受理未知或正在提交时，不允许通过换键、参数、云环境或设备绕过；仅改offset／变量说明未改变发送给求解器的问题，归档也不解除占用。已明确受理后的主动新任务仍需新的明确确认。taskName唯一不是远端幂等证明，工具不自动查单解除unknown。

云状态0排队、1运行、2成功、3失败／取消；本地创建success只表示受理，详情finished后独立取结果。result_pending／result_invalid区别于设备failed；并发查询晚到的旧状态或错误不能覆盖已完成结果。provider_energy与原QUBO复算值分别保留，设备耗时与端到端耗时不同。

网页位置取该笔快照。已核实详情路由缺失时只给已知主页与任务号查找指引；未知入口不猜域名、API路径或Benchmark页面。旧v1缺来源时保留缓存，不用当前配置补造历史。查看不提交／重算，停止本地等待不表示设备已取消。

## 验证边界

程序回归、MCP stdio与专家CLI的隔离服务集成分别留证；它们不替代真实Host／LLM、设备数学黄金样例、实际硬件执行或费用验收。本地源码与配置页可用也不代表相关云端点已部署。

SIT／PROD目录及任务必须同环境；新目录不可用时明确报错，不使用固定名单。发版、推送、用户安装与真实设备参数合同另按获准计划推进。
