# 求解器管理页启动与资源生命周期规范

本规范归属YJ-REQ-0105，适用于MCP、Core及专家CLI共享的管理页启动入口。目标是重复打开可继续使用已有管理页，同时让进程、监听端口和会话登记有明确上限与回收路径。

## 启动与复用

- 同一当前用户、同一规范化配置文件、同一固定环境，跨管理页构建最多保留一个托管管理进程及一个loopback监听端口。同构建重复／并发打开复用相同URL和PID，不同构建受保护交接；单纯启动／身份探测不作为业务活动续用，当前闲置截止以真实服务状态为准。
- 构建身份由明确的管理协议版本、页面及运行时实现与策略常量确定，不能只依赖产品版本号。配置路径需处理符号链接别名；不同用户、配置或固定环境隔离，不兼容构建须在同作用域完成交接。
- 创建进程前取得跨进程启动所有权，等待须有上限。不能通过先启动多份进程、再保留一份来通过防重验收。失败不自动反复增开进程。
- 复用须核验受保护的本地服务身份、会话、配置、构建与有效期。PID存活或端口可连单独都不能证明是原管理页。会话登记独立于设备连接配置，目录及文件仅当前用户可读写，不把nonce写入普通日志。
- 仅监听127.0.0.1，由操作系统分配空闲端口。不扫描、抢占或停止其他应用的端口，不把检测设备或云接口作为启动健康检查。

## 有效期与结束

- 首次打开／恢复可见及真实交互延长90秒使用保护，进行中的真实管理操作有界保护，没有从启动起15分钟／1小时的业务硬上限；所有交互保护失效且无操作后，连续闲置默认30分钟才回收。
- 可见页每30秒只向本机发健康心跳，心跳不延长使用保护；隐藏／离开时停止并尽力释放，通知丢失由保护到期处理，不把设备／云查询当心跳。宿主持续报告visible／focused不能无限保活；一页隐藏不能释放其他正在使用的页。
- 父CLI正常退出后管理页仍可使用；浏览器关标签／刷新／网络断开不作为唯一清理依据。不持续轮询设备或云目录，不新增常驻启动broker。
- “结束管理”及到期先停止接收和使会话失效，再有界收尾连接，释放监听口、托管进程、定时器及所属会话登记。关闭须幂等；同会话其他标签也随之失效。低层进程内页面原语不得退出调用它的宿主进程。
- 长连接、半截请求或未完成的只读查询不能无限延迟退出。托管sidecar在收尾期限后自行退出；不得改变、取消或删除任何远端求解任务。
- 会话失效后才完成的请求体，必须在写配置或开始新查询前再次核验有效性；只把响应改为403不能代替阻止副作用。所有声明的保护期限按总耗时计，持续收到少量数据不能重置为无限空闲等待。
- 正常SIGTERM／SIGINT按同一清理路径处理。SIGKILL／崩溃可能留下登记；下次启动基于所有权及活性核验恢复。损坏或有歧义的活登记须给可操作错误，不能盲目复用、增开或杀PID。
- 就绪超时、启动失败、登记写入失败及等待中断均须回收本次确实创建的子进程与资源。只能对本次持有的ChildProcess执行终止，不能因磁盘登记的PID就终止进程。

当前候选使用以下保护值，实际执行与构建指纹另见候选实施记录；它们是资源保护边界，不代表设备或云服务性能承诺。

| 项目 | 上限／设置 |
| --- | --- |
| 单次启动就绪 | 5秒 |
| 并发启动等待 | 8秒 |
| 本地服务身份核验 | 500毫秒 |
| 关闭连接的正常收尾 | 250毫秒 |
| 托管进程整体收尾 | 1秒 |
| 默认闲置回收预算 | 最后交互保护结束且无进行中管理操作后30分钟 |
| 交互保护／健康心跳间隔 | 90秒／30秒，普通心跳不续长保护，不拉设备／云数据 |

各阶段分别计时，启动失败清理可另用最多1秒收尾预算。测试可以缩短内部预算；旧lifetimeMs若兼容保留只能映射闲置预算，不隐藏绝对寿命。协议／构建身份须区分旧绝对TTL与新idle版本。

## 草稿与恢复提示

- 已保存连接不随服务回收删除。未保存内容仅作草稿备份，使用当前用户及规范配置的本机私有存储，默认24小时、最多10份；按请求清理，不另起定时清理进程。token与草稿内容不进普通日志。
- 列表先返回元信息，用户明确恢复时再读取内容；恢复不自动变成已保存连接，不覆盖另一份正在输入的表单。保存仍经过原验证，取消及成功保存清理对应草稿，generation及有界墓碑阻止旧请求复活或覆盖较新代。
- 新服务／新端口可发现未过期草稿；仅把草稿存在某个origin的sessionStorage不能当成跨回收恢复。备份失败明确告知，不宣称已恢复保障。
- 页面提前说明闲置回收规则；后台可展示临近回收状态，前台返回时核验／续用，已结束则给工具重开路径及真实草稿状态。浏览器冻结不保证实时通知，不抢前台、不自动拉起新进程；旧动态地址不是永久入口。

## v3版本交接及真实交互约束

登记及互斥按用户、规范配置、固定环境和v3协议确定，不按每个build开槽；实际页面与运行时函数、策略常量、正文限额参与build身份。相同build直接复用，不同build经受保护的`/api/handover`退役旧服务。近期交互、在途操作、已认证且正文未收完的请求、未确认／过期草稿或编辑保护登记失败均拒绝交接，不增开。正文读取有10秒绝对期限，半截正文不算idle活动。确认旧PID退出后才创建新版；失败清理本次资源并允许重试，不盲杀、不复活旧会话。不同固定环境仍独立。

首次打开／恢复可见及isTrusted鼠标、键盘、输入、滚动可取得90秒使用保护；30秒普通心跳声明interactive=false，不延长保护。最后保护失效且无操作后计完整30分钟idle，持续真实交互可一直延续。此规则取代仅凭可见性永久续用：宿主错误将后台页报告visible／focused也不能无限保活。服务不可达后停止自动心跳重试，真实操作可有限重试；不修改浏览器可见性值，不按UA硬编码。

编辑保护按page_id／sequence登记dirty草稿id／generation，交接时核对实际持久备份与保留期；旧seq不能覆盖新状态。clean历史可回收；登记容量不足或未确认保护必须阻止自动交接并提示，不把登记失败当作安全。旧v2缺少原子编辑保护，旧session或启动中owner登记阻止新服务；必须通过旧页确认结束或旧idle回收后重开，不能依据一次状态快照向旧服务发close。

验收覆盖新版并发、旧启动窗口、半截body、草稿过期／失败／容量、仅改运行常量、旧PID退出及原端口重绑、新版启动失败恢复、实际宿主双页均visible时的无交互回收。短测试预算不能冒充实际等待生产30分钟。浏览器标签保留与监听端口回收分开计证。前文旧的“不同构建隔离”和“可见即持续续用”以本节v3规则为准。

## 必测用例与判定

| 情形 | 必须观察的结果 |
| --- | --- |
| 同进程连续10次打开 | 仅1次创建，相同URL／PID／端口；纯启动／身份探测不延长闲置，实际使用可续用 |
| 6个独立父进程并发打开同配置 | 仅1个托管进程和监听端口，调用方均得到同一会话；不是多份启动后退出的假防重 |
| 配置目录符号链接别名／不同配置 | 别名复用；不同配置隔离，不能串用户连接或会话 |
| 父CLI退出、反复刷新页面 | 页面仍可使用，无新增sidecar或持续轮询 |
| 主动结束、短闲置预算到期、SIGTERM／SIGINT | 会话拒绝后续访问，进程退出、登记移除，原监听口能由新测试监听器实际重新绑定 |
| 连续3轮打开／结束 | 每轮结束后没有托管进程、端口或锁累计，下一次能正常创建 |
| 慢连接／半截请求／正在读取信息时结束 | 在声明的收尾期限内释放本地资源，不等待浏览器配合，不触发远端任务操作 |
| SIGKILL后重新打开、孤立或损坏登记 | 安全识别并恢复或清楚报错，不复用错误服务，不终止登记中无关PID，不无限等锁 |
| 启动失败／不就绪／崩溃窗口 | 只回收本次已创建资源，调用有界失败，下次可恢复，不悄悄保留活子进程 |
| 源码／Node bundle入口 | 相同启动与回收规则；其他发行制品未实际执行时分别标注未验 |
| 前台超最初期限、多页切换、租约遗失、管理操作进行中 | 使用中继续可用，全部离开后完整闲置预算才回收；健康探测不冒作活动 |
| 草稿跨新会话／端口恢复、备份失败、取消／保存／旧代回执 | 显式恢复且不覆盖输入、不自动保存配置；状态真实、过期和上限受控、旧回执不复活 |

进程退出断言与端口重新绑定都要留证，不能只检查返回了close成功，也不能只以PID不存在当作端口释放证据。会话nonce从报告、截图和外发消息移除；压力与故障注入只用隔离配置与loopback依赖。

Node底层关闭可能需要同时处理活动与空闲连接；生命周期测试以实际回收为准，参见[HTTP服务关闭接口](https://nodejs.org/api/http.html#servercloseallconnections)。跨进程登记依赖当前用户的本地文件系统，独占创建行为参见[文件系统标志](https://nodejs.org/docs/latest-v18.x/api/fs.html#file-system-flags)；不将本地互斥保证外推到不支持相同语义的网络文件系统。
